# IdeaGrid 사용법

## 실행

Node.js 20.9 이상과 pnpm 11.9 이상이 필요합니다.

```bash
pnpm install
pnpm dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

같은 네트워크의 다른 기기에서는 실행 안내에 나온 `Network` 주소를 엽니다. 개발 서버는 실행 중인 컴퓨터의 주소를 자동으로 허용합니다. 네트워크가 바뀌면 서버를 다시 실행하세요.

페이지는 보이지만 버튼이 반응하지 않으면 개발 서버를 다시 실행한 뒤 브라우저를 새로고침하세요. 기존 서버가 실행 중이라는 안내가 나오면 안내된 주소를 사용하세요.

## 프로젝트 만들기

1. 대시보드에서 프로젝트 이름을 입력합니다.
2. **새 프로젝트 만들기**를 누릅니다.
3. 프로젝트는 현재 브라우저의 저장 공간에 자동 저장됩니다.

## 장면 편집

1. 상단 입력란에 구현할 아이디어를 적습니다.
2. 왼쪽에서 자산을 검색한 뒤 클릭하거나 캔버스로 끌어 추가합니다.
3. 객체를 선택하고 오른쪽에서 핵심 조건을 입력합니다.
4. **세부 속성·출처 보기**를 열면 단위와 출처를 수정할 수 있습니다.
5. 3D 축 또는 평면 보기의 드래그와 방향키로 객체를 이동합니다.
6. **객체 연결**을 누른 뒤 출발 객체와 대상 객체를 차례로 선택합니다.
7. 관계 종류를 선택하여 의존, 전력 공급, 보호 등의 의미를 지정합니다.

## 영향과 분석 확인

태양과 사람 또는 장비를 함께 추가하면 영향 방향과 다음 자산 추천이 표시됩니다. 대상 객체에 실제 태양 중심 거리(AU)를 입력하면 기준 입사 복사조도가 계산됩니다. 화면상의 배치 거리는 실제 거리로 계산되지 않습니다.

**아이디어 분석**을 누르면 현재 객체, 관계, 속성을 기준으로 결과가 생성됩니다. 값을 바꾼 뒤 다시 분석하면 변경된 결과를 확인할 수 있습니다.

## 저장과 내보내기

- 같은 브라우저·주소·포트에서 새로고침하면 프로젝트가 복원됩니다.
- 다른 브라우저나 다른 포트에서는 저장된 프로젝트가 보이지 않습니다.
- 브라우저 데이터를 지우면 프로젝트도 삭제될 수 있으므로 중요한 작업은 **JSON 내보내기**로 보관합니다.
- 3D 장면은 PNG로, 분석 결과는 Markdown 또는 인쇄/PDF로 내보낼 수 있습니다.
- 실행 취소 이력은 새로고침하면 초기화됩니다.

## 선택 검증

```bash
pnpm run verify
```
